# Publish AML_Data_Science_Project

The linked GitHub app could read the new repository but GitHub denied its write attempt with HTTP 403.

1. Open https://github.com/mohammedmia1/AML_Data_Science_Project and choose **uploading an existing file** (or Add file > Upload files).
2. Extract this ZIP on your computer. Upload the **contents** of the extracted folder, preserving directory structure. GitHub web upload may not preserve empty folders; that is fine. For a reliable directory-preserving upload, use `git add .` and `git push` locally, or GitHub Desktop.
3. Commit the changes as the new repository's first commit.
4. In Settings > Pages, select **Deploy from a branch**, **main**, and **/docs**, then save.
5. Open https://mohammedmia1.github.io/AML_Data_Science_Project/ and check the 389 positive labels, capacity 2,747, slider, and links.
6. This package does **not** contain a verified refreshed Tableau workbook or the original SQL script. Add them only after verification.
7. Do not delete the previous repository until the new site and its source materials pass verification.

Source data TSV files are intentionally excluded because they are large.
